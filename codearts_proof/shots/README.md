# 截图合集（`codearts_proof/shots/`）

官方要求中截图合集为可选项，但**"会话 md 能看出人怎么纠偏 AI"是 25 分的核心**，截图是最直接的旁证。本目录只放**本人拍摄**的真实截图。

## 清单

| 编号主题 | 拍什么 | 何时 | 文件名建议 |
|---|---|---|---|
| 契约冻结会 | 契约评审现场的屏幕（`CONTRACT.md` / `design.md` 的 `C-*` 条目）+ 参会人 | D0–D1 | `D1-contract-freeze.png` |
| 检查点 1 | 一份需求清单 + 一个仓库跑出的第一份报告（含轨迹段） | D5 | `D5-checkpoint-1.png` |
| 代码冻结 tag | `git tag freeze-v1` 的终端输出 + 对应 commit | D6 | `D6-freeze-v1.png` |
| 提交成功页 | 赛事平台提交成功回执（含作品名与时间） | D6 | `D6-submit-ok.png` |
| 码道会话 | 关键一次会话的界面（需求 → 生成 → 测试） | 按需 | `D<0-6>-codearts-session-N.png` |

## 命名规则

`D<0-6>-<主题>.png`：天号（0–6）+ 主题短语（小写英文、连字符分隔），同一天多张加序号，例：

```
D2-extractor-refactor.png
D3-matcher-debug-1.png
D6-freeze-v1.png
```

## 红线

- **截图由本人拍摄后放入，不得使用生成图**（AI 生成、PS 合成、伪造界面一律视为造假）。
- 截图内容不得含真名、学号、手机号、密钥、真实项目源码以外的隐私信息；确需出现的，先打码。
- 文件放进来后**不要改名或补拍**冒充当天；补拍需在说明里注明"补拍于 D<x>"。
